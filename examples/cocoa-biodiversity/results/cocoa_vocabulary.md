# Cocoa-biodiversity working controlled vocabulary

Seeded from the framing question in `context/research_question.md`. Extended as papers are processed.

## subject_codes (biodiversity / management drivers)

| code | definition | also covers |
|---|---|---|
| `shade_tree_species_richness` | Number of shade-tree species per cocoa plot. | tree species richness, shade tree diversity |
| `shade_tree_density` | Density of shade trees per hectare. | shade tree density, canopy density |
| `shade_cover_percentage` | % of cocoa canopy area shaded. | shade level, shade cover |
| `functional_diversity_of_shade_trees` | Functional-trait diversity of companion/shade tree community. | functional trait diversity, FD |
| `agroforestry_vs_monoculture` | Categorical: cocoa agroforestry system vs full-sun monoculture. | full-sun vs shaded cocoa, polyculture vs monoculture |
| `pollinator_abundance` | Abundance of pollinators (predominantly Forcipomyia midges). | midge abundance, pollinator density |
| `pollinator_diversity` | Diversity of pollinator species. | pollinator species richness |
| `natural_enemy_abundance` | Abundance of predators / parasitoids of cocoa pests. | predator abundance, biocontrol agents |
| `epiphyte_abundance` | Density/cover of epiphytes on cocoa or shade trees. | epiphyte cover |
| `soil_biodiversity` | Soil microbial / faunal diversity. | soil microbial diversity, soil fauna |
| `bird_abundance` | Bird abundance / diversity in cocoa farms. | bird diversity |
| `tree_stand_age` | Age of cocoa stand. | cocoa stand age, plantation age |
| `cocoa_density` | Density of cocoa trees per hectare. | cocoa stand density |
| `fertiliser_input` | Application of synthetic or organic fertiliser. | fertiliser use, nutrient input |
| `pesticide_input` | Application of pesticides (insecticides, fungicides). | pesticide use, agrochemical input |
| `intensification_level` | Composite or categorical of management intensity (full-sun, low-input, high-input). | intensive vs extensive management |

## object_codes (yield-side outcomes)

| code | definition | also covers |
|---|---|---|
| `cocoa_yield` | Cocoa bean yield per unit area (kg/ha, t/ha) or per tree. | bean yield, productivity |
| `pod_count` | Number of cocoa pods per tree or per hectare. | pod number, pod production |
| `pod_loss_to_pests` | Pod loss attributable to pests (mirids, capsids) or diseases (black pod). | pest damage, capsid damage, black pod loss |
| `bean_weight` | Average weight of cocoa beans. | bean size, individual bean mass |
| `farmer_net_returns` | Profitability — yield × price − inputs. | farmer income, net returns |
| `pollination_success` | Proportion of flowers/cushions successfully pollinated. | pod set, fruit set |

## Cross-domain / mediating

| code | definition |
|---|---|
| `microclimate_buffering` | Reduced temperature/humidity variation under shade. |
| `nutrient_cycling` | Litterfall → nutrient return to soil. |
| `soil_organic_carbon` | Soil C stocks. |
